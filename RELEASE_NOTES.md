# Clipboard Exchange v1.0.0

## Новое

- Нативный Windows-клиент: tray, глобальные хоткеи, отправка clipboard/выделения, история, вставка текста, deep links и E2EE. Настройки и локальная история защищены DPAPI.
- Desktop-прототип для macOS на Electron.
- Ограниченный API текстовой истории для desktop; большие комнаты больше не блокируют отправку.

## Исправления

- Одноразовые файлы сохраняются при HEAD, предпросмотре, условных запросах и ошибках передачи.
- Фоновая очистка не пересекается с активными файловыми операциями и не блокирует новые запросы в ожидании долгой передачи.
- Повторное завершение upload идемпотентно, в том числе после перезапуска сервера.
- Большие передачи используют тайм-аут простоя вместо общего ограничения в 30 секунд.
- Потоковая расшифровка и ZIP учитывают скорость потребителя и поддерживают отмену.
- Windows-клиент корректно передаёт emoji и другие символы вне BMP.
- Исправлен обход rate limit через подставленные proxy-заголовки.
- Readiness проверяет БД и файловое хранилище.

## Обновление

1. Остановите сервис и сделайте backup БД вместе с каталогом файлов.
2. Обновите сервер: SQLite автоматически перейдёт на схему **7**. Старый сервер эту схему не откроет; для отката нужна резервная копия.
3. Затем обновите Windows-клиент: он использует новый endpoint `/history`.
4. При использовании `--trust-proxy` обновите конфигурацию по примеру README: последний доверенный proxy должен перезаписывать X-Forwarded-For реальным адресом клиента. Forwarded игнорируется.

Download-once остаётся best-effort подтверждением передачи браузеру, а не гарантией записи на диск или запретом параллельного скачивания.

Windows installer подписывается только при настроенном сертификате CI. macOS-прототип выпускается без notarization; ОС может показывать предупреждение при установке.
